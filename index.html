WGSL: a single-thread loop stops early

One compute dispatch, one active invocation. The shader computes a 6,528-entry cost table (VP8CalculateLevelCosts from libwebp): an outer loop over 96 tables and, per entry, an inner loop that runs while a bit pattern has bits left. The page compares the result with the same computation computed ahead of time (data.json). The shader is unmodified generated WGSL and validates with naga.

Observed (2026-11-24): NVIDIA RTX 4070, Chromium (D3D12): 6528 of 6528 right. AMD Radeon RX 590, Chrome 158, D3D12, driver 31.0.21925.1001: 136 of 6528 right, first wrong at index 136 (got 0, expected 512).
